# Patterns

- `warp-check-tile.svg`: a seamless 480px tile of the warp check in the Lavender colorway (cells `#cdb7f6`, ground `#f8f0e3`). Repeat it edge to edge for print. For other colorways, regenerate with `Glint.WarpCheck.geometry({cols: 8, rows: 8, cell: 60, seed: 7})` and swap the cell colour.
- `monogram-tile.svg`: the emboss repeat, single ink `#29252c`. One tile is 36 units square: a sparkle in the middle and a round medallion at each corner (the medallion is where the initials go once the name is final). Use it at 30 mm or larger on the strap.
