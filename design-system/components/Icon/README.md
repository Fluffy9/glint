# Icon

The house icon set: drawn on a 24px grid with 2px strokes, square caps and mitred corners, in `currentColor` (so `ink` by default). `warning` is the one filled icon (the `warning` triangle).

Names: search, close, check, heart, user, sync, moon, bolt, info, warning. Sizes 16, 20 (default) or 24; 32 inside alerts. Pass `label` when the icon carries meaning on its own. Add new icons in the same style; don't mix in a third-party set.
