# Input

A single-line text field: `surface` well, 2px `line` outline, `elev-2`. Pass `label` (rendered as an uppercase mono label above), optional `icon` (trailing, e.g. `search`), and either `help` (`ink-muted`) or `error` (turns the well `danger-soft` and the message `danger`). Placeholder text is a hint, never the label. Every other prop goes to the `<input>`.
