# ProgressRing

The band has no screen, so this is its face: the one status a person checks. An outlined ring, `surface-sunken` track, `accent` arc, and the number in the `metric` style at the centre with a mono label.

- At 100% a Sparkle appears above the number: the visual twin of the band's "goal hit" haptic (see Surfaces).
- One large ring per screen (160px); small ones (96px) only in lists.
- Props: `value` (0–1, may exceed 1), `display` (the text in the middle; defaults to a percent), `label`, `size`, `thickness`, `ariaLabel`.
