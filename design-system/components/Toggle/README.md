# Toggle

An on/off switch for settings that take effect immediately (no Save). Pill track in `surface-sunken` that fills `accent` when on; the square-ish knob keeps its `line` outline. Renders a real checkbox with `role="switch"`, so the whole label is clickable.

Props: `label`, `checked` + `onChange` (controlled) or `defaultChecked`, `disabled`. Write labels as the thing that is on ("Haptic nudge when inactive"), not as a question.
