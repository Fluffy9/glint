# Glint slide box mockup

- `index.html`: the interactive 3D box. Open it in a browser. Drag to turn it. Chips switch the tray position, side accent pattern, size and colourway. It works offline except for the fonts, which load from Google Fonts.
- `renders/`: PNG images (2720 px wide) of the box in four colourways, closed and open, plus a star-lattice version and a comparison of the four wavy-check options.

This is a presentation mockup, not a print file. Box dimensions (110 x 110 x 60 mm sleeve) are placeholders, and the sleeve and tray clearances are made up.
